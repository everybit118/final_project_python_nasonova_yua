Автоматизированный мониторинг и реагирование на угрозы

Скрипт выполняет автоматический сбор и анализ данных об угрозах из двух источников:

Vulners API — поиск уязвимостей (CVE) с высоким CVSS-баллом (от 7 до 10). Скрипт получает список из 10 актуальных уязвимостей и выделяет критические (CVSS ≥ 9).

VirusTotal API — проверка списка подозрительных IP-адресов (известные Tor exit-ноды). Для каждого IP получаем количество детектов malicious и suspicious от антивирусных движков.

После анализа скрипт имитирует реагирование:
- для критических уязвимостей — выводит предупреждение о необходимости обновления;
- для вредоносных IP — имитирует блокировку с выводом сообщения в консоль.

Результаты сохраняются в файл report.json, а визуализация — в файл chart.png (два графика: распределение CVSS-баллов и анализ IP-адресов).


Выходные файлы

- report.json — отчёт с данными об уязвимостях и результатами проверки IP
- chart.png — графики с визуализацией результатов
